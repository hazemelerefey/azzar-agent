# Azzar Market Types

Shared TypeScript types for the AZZAR agent marketplace.

[Issues](https://github.com/hazemelerefey/azzar-agent/issues)

</div>

## What it is

`@azzar/market-types` holds the shared type definitions used across the
marketplace: agent listings, department definitions, install manifests, and
the contracts between publishers, the marketplace, and clients. It is a
dependency of `@azzar/market-sdk`.

## Installation

```bash
pnpm add @azzar/market-types
```
