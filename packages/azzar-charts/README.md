## Installation

> \[!IMPORTANT]\
> This package is [ESM only](https://gist.github.com/sindresorhus/a39789f98801d908bbc7ff3ecc99d99c).

To install Azzar UI, run the following command:

[![][bun-shield]][bun-link]

```bash
$ bun add @azzar/charts
```

### Compile with NextJS

> \[!NOTE]\
> By work correct with nextjs ssr, add `transpilePackages: ['@azzar/charts']` to `next.config.js`. For example:

```js
// next.config.js
const nextConfig = {
  // ...other config

  transpilePackages: ['@azzar/charts'],
};
```

## Local Development

You can use Github Codespaces for online development:

[![][codespaces-shield]][codespaces-link]

Or clone it for local development:

```bash
$ git clone https://github.com/hazemelerefey/azzar-agent.git
$ cd azzar-charts
$ bun install
$ bun start
```
