# Azzar Desktop IPC Typings

TypeScript typings for AZZAR desktop IPC channels.

[Issues](https://github.com/hazemelerefey/azzar-agent/issues)

</div>

## What it is

`@azzar/desktop-ipc-typings` defines the typed contracts for inter-process
communication in the AZZAR desktop app: the channels, payloads, and responses
shared between the main process and renderers.

## Installation

```bash
pnpm add @azzar/desktop-ipc-typings
```
