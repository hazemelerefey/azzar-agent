# Azzar Market SDK

JavaScript SDK for the AZZAR agent marketplace.

[Issues](https://github.com/hazemelerefey/azzar-agent/issues)

</div>

## What it is

`@azzar/market-sdk` is the client SDK for the AZZAR agent marketplace, where
ready-made department agents are published, discovered, and installed. It
handles listing, authentication, and installation against the marketplace API.

## Installation

```bash
pnpm add @azzar/market-sdk
```
